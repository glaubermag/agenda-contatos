🧪 Desafio Técnico – Desenvolvedor(a) Frontend Vue.js (Pleno/Sênior)
Objetivo:
Criar uma aplicação web simples, responsiva e componentizada usando Vue.js com foco em boas práticas, consumo de API e organização de código.

📌 Descrição do desafio:
Desenvolva uma aplicação chamada "Agenda de Contatos" com as seguintes funcionalidades:

Funcionalidades obrigatórias:
Listagem de contatos
   - Consumir dados de uma API REST simulada (sugestão abaixo).
   - Mostrar uma lista com nome, e-mail e telefone.
   - Busca por nome ou e-mail
   - Campo de busca que filtre os contatos em tempo real.

Adicionar novo contato
  - Formulário com validações básicas (nome, e-mail e telefone obrigatórios).
  - Novo contato deve ser adicionado à lista localmente (não precisa persistir).

Responsividade básica

Aplicação deve funcionar bem em desktop e mobile.

Requisitos técnicos:
Vue.js (2 ou 3 – você escolhe);

Vue Router;

Gerenciamento de estado (Vuex ou Pinia);

CSS moderno (pode usar Tailwind, Bootstrap ou CSS puro);

Estrutura de componentes reutilizáveis;

Organização de pastas clara e modular;

Consumo de API com fetch ou axios.

API simulada:
Use esse endpoint gratuito como base de dados:
https://jsonplaceholder.typicode.com/users

Ou, se preferir, crie um mock com json-server ou axios-mock-adapter.

⚙ Diferenciais (não obrigatórios, mas valorizados):
Ao clicar em um contato, abrir um modal com detalhes.

Implementação com Capacitor (aplicativo híbrido);

Atenção à acessibilidade (uso de ARIA, foco etc.);

Animações suaves (transições, loaders etc.);

Uso de Design System (se tiver algum seu, ou crie um leve com 2–3 componentes base).

Suba seu código no GitHub (público ou privado com acesso liberado);
